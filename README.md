# vibe-compass

## 概要

ESP32と地磁気センサーを使い、北を向いたときに振動モーターが動作する試作品です。

スマートフォンの画面を見続けるのではなく、方角を「振動で感じる」ことで、自分の感覚を使いながら目的地へ向かう体験を目指しています。

まずは、地磁気センサーが北を検知したときに振動するシンプルなデバイスを試作しています。

## コンセプト

振動コンパスは、方角を画面で確認するのではなく、身体感覚として受け取るための試作ガジェットです。

現在の試作では、本体の「前」と決めた方向が北を向いたときに振動モーターが動作します。北に近づくほど振動の間隔が短くなり、真北付近では連続振動するようにしています。

## 現在の状態（v0.4）

* ESP32と地磁気センサー（AE-BM1422AGMV）を接続済み
* 地磁気センサーから方位を取得し、北方向を判定
* 北に近づくほど振動間隔が短くなり、真北付近では連続振動する
* 電池ボックス（単4×3本）＋5V昇降圧DC-DCコンバーターで、PCなしで動作する
* 起動時とキャリブレーション完了時に振動で状態を通知
* 段ボールの一次筐体（試作機1号）に組み込み済み
* 屋外・電池駆動・手持ちで、コンパスとほぼ同じ真北で連続振動することを確認（2026-11-03）
* USBでPCにつなぐと、Serial Monitorで診断情報（`[DIAG]`）を確認できる

## 使い方

1. 電池ボックスのスイッチをONにする
2. 起動後、短い2回の振動で起動を確認する
3. 起動直後の10秒間、本体を水平にしてゆっくり1周〜1周半回す
   * できれば、机やベンチなどの平らな場所に置いたまま回す
4. キャリブレーション完了後、長めの2回の振動で完了を確認する
5. 本体の「前」を北に向けると振動する

反応がおかしい場合は、ESP32のENボタンを押してリセットし、再度キャリブレーションを行います。

## キャリブレーションについて

起動直後に10秒間、本体を水平にして回転させます。

これは、地磁気センサーのX/Y方向の中心ズレを補正するための処理です。PCや外部コンパスがなくても使えるようにするため、起動時に自動でキャリブレーションを行う仕様にしています。

うまくいかないと、方位が数十度ずれることがあります。

* 回すときに大きく傾けない
* 10秒の間に1周以上回す（止まったままだと方位がばらばらになる）
* コンパス・スマートフォン・PCを30cm以上離す

現在のコードは、キャリブレーションがうまくいったかどうかを判定していません。失敗しても完了の振動が鳴るので、反応がおかしいときはやり直してください。

## バージョン

### v0.1：北検知＋振動成功

* ESP32と地磁気センサーを接続
* 地磁気センサーから方位を取得
* Serial Monitorで `n` を入力した時点の方位を北として記録
* 記録した北方向を向いたときに振動モーターが動作

### v0.2：北への近さを振動で表現

* 北からのズレ角度を計算
* ズレ角度に応じて振動パターンを変化
* 北に近づくほど振動間隔が短くなる体験を検証
* 真北付近では連続振動するように調整

### v0.3：自律北検知版

* Serial Monitorで `n` を入力して北を登録する方式を廃止
* 地磁気センサー自身の方位計算を使って北を判定
* `SENSOR_FORWARD_OFFSET` により、基板の「前」方向とセンサー値のズレを補正
* PCや外部コンパスなしで動作可能
* 起動時とキャリブレーション完了時に振動で状態を通知
* 不規則だった断続振動を改善し、北に近づくほど振動間隔が短くなるように修正

### v0.4：補正値の変更（2026-11-03）

* `SENSOR_FORWARD_OFFSET` を 99.3 → **89.3** に変更
  * 屋外・電池駆動の実測で、連続振動する向きが毎回コンパスの北より東に5〜20°（平均約11°）ずれていたため、西へ10°ずらした
* 屋外・電池駆動・手持ちで3回テストし、3回ともコンパスとほぼ同じ真北で連続振動することを確認
* v0.3に診断用のSerial出力（`[DIAG]`）を追加した診断版をベースにしている。北判定・振動パターン・平滑化などの動作ロジックはv0.3と同じ
* コード：`08_offset_89.3/`

v0.1〜v0.3のコードはリポジトリから削除しました。必要なときはコミット履歴から取り出せます。

## 現在の設定メモ

* 振動モーター：GPIO25（2SC1815経由、ベース抵抗1kΩ）
* I2C SDA：GPIO21
* I2C SCL：GPIO22
* 地磁気センサー：AE-BM1422AGMV（I2Cアドレス `0x0E`）
* 北判定範囲：±25度
* 真北付近の連続振動範囲：±5度で連続振動に入り、±7度を超えると抜ける
* `SENSOR_FORWARD_OFFSET`：89.3度
* Serial Monitor：115200 baud

`SENSOR_FORWARD_OFFSET` は、実際の使い方（屋外・電池駆動・一次筐体に入れた状態）で、本体の「前」を北に向けたときの向きをもとに決めています。部品の配置や筐体を変えたら、同じ条件で測り直します。

### Serial Monitorのコマンド

* `c`：キャリブレーションをやり直す
* `i`：設定値と説明を表示する

## 注意点

地磁気センサーは、周囲の金属や磁石、モーター、モバイルバッテリー、スマートフォンなどの影響を受けます。

* **室内では建物の鉄骨などの影響で、方位が20°以上ずれることがある**。補正値の確認は屋外で行う
* コンパスやスマートフォンを10cmほどに近づけると、方位が10°前後ずれることがある。測るときは30cm以上離す
* 屋外テストでは、金属製の柵、自転車、車、ベンチ、マンホール、建物などから離れた場所で確認する
* 傾き補正をしていないので、本体はなるべく水平に持つ（左右に15°傾けると約12〜14°ずれる）
* **USBでPCにつなぐときは、電池ボックスのスイッチをOFFにする**（USBと電池からの同時給電は禁止）

## 外テスト用チェックリスト

### 1. 持ち出す前の確認

* ESP32に最新のv0.4コードを書き込んだ（起動時のSerial表示が `Vibe Compass v0.4 DIAGNOSTIC (OFFSET 89.3)`）
* 電池でESP32が起動する
* 起動時の振動合図が分かる
* キャリブレーション完了時の振動合図が分かる
* 本体の「前」が分かる
* 配線が抜けにくい状態になっている
* モーター、地磁気センサー、ESP32、電池の位置関係を記録した

### 2. テスト場所

* 公園の広場など、金属製の柵や手すり、自転車、車、電柱、マンホールから離れた場所で試す
* コンパスを持って2〜3m歩き回り、北の向きが変わらないことを確かめる
* スマートフォンやPCを地磁気センサーに近づけすぎない（30cm以上離す）
* まずは広めで安全に立ち止まれる場所で試す
* 歩きながら試す前に、立ち止まった状態で確認する

### 3. 起動・キャリブレーション

* 電池ボックスのスイッチをONにして起動する（USBでPCにつなぐときは電池をOFF）
* 起動合図の振動を確認する
* 10秒間、本体を水平にしてゆっくり1周〜1周半回す（できれば平らな場所に置いたまま）
* キャリブレーション完了の振動を確認する
* 反応がおかしい場合は、ESP32のENボタンを押してやり直す

### 4. 北検知の確認

* 「前」を北方向に向けたときに振動する
* 北から少し外すと断続振動になる
* 北から大きく外すと振動が止まる
* もう一度北に戻すと再び振動する
* 真北付近で振動が不規則にならない
* 北に近づくほど振動間隔が短くなる感覚がある
* 真北付近で連続振動する
* 連続振動した向きが、コンパスの北から何度ずれているかを記録する

### 5. 環境による変化の確認

* 場所を少し変えても北検知できる
* 建物の近くと離れた場所で反応に違いがあるか確認する
* 金属物の近くで反応が乱れるか確認する
* スマートフォンを近づけたときに反応が変わるか確認する
* 手に持ったときと、平らな場所に置いたときで反応が変わるか確認する

### 6. 持ちやすさ・体験の確認

* 片手で持ちやすい
* 本体を水平に保ちやすい
* 「前」の方向が直感的に分かる
* 振動の強さが分かりやすい
* 振動の間隔変化で北に近づいている感覚がある
* 画面を見なくても状態が分かる
* 歩きながら使えそうか確認する

### 7. テスト後に記録すること

* テスト日
* テスト場所
* 天気や周囲の環境
* 給電方法（電池／USB）
* キャリブレーションの方法（手持ち／平らな場所に置いた）
* キャリブレーションがうまくいったか
* 連続振動した向きと、コンパスの北とのずれ
* 振動の強さは十分だったか
* 誤反応が起きた場所や状況
* 配線や持ち運びで不安だった点
* 次に直したいこと
